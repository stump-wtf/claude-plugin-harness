# claude-plugin-harness

Claude Code and Crush plugin for configuring and using [harness](https://gitea.stump.rocks/stump.wtf/harness) — the agent supervisor TUI.

## Skills

- **harness-config** — Author and edit `harness.toml` files, covering all config fields including the agent abstraction layer (`prompt`, `model`, `auto_accept`, `max_turns`, `quiet`).

## Installation

### Claude Code

```bash
claude plugin install https://gitea.stump.rocks/stump.wtf/claude-plugin-harness
```

### Crush

Add to your `crush.json` skills paths or clone into your skills directory.
